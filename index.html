Разовая настройка, минут на 15. Всё бесплатно. Делает один из вас, второй потом просто открывает ссылку.

1

База данных Firebase здесь хранится ваш список

  1. Откройте console.firebase.google.com, войдите через Google, нажмите «Create a project». Название любое, Google Analytics можно выключить.
  2. Слева: Build → Firestore Database → Create database. Регион eur3 (europe-west), режим «Start in production mode».
  3. Вкладка Rules: замените всё на правила ниже и нажмите Publish.
  4. Шестерёнка вверху слева → Project settings → внизу «Your apps» → значок </> → любое имя → Register app. Скопируйте блок firebaseConfig и вставьте в поле ниже.
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /rooms/{room} {
      allow get, create, update: if room.size() >= 20;
      match /{rest=**} {
        allow read, write: if room.size() >= 20;
      }
    }
  }
}

2

TMDB постеры, кадры, трейлеры, где смотреть

  1. Зарегистрируйтесь на themoviedb.org и подтвердите почту.
  2. Откройте Settings → API и запросите ключ (тип Developer, использование Personal). В анкете можно указать адрес этого сайта.
  3. Скопируйте API Read Access Token (длинный, начинается на eyJ) или короткий API Key.
3

OMDb рейтинги IMDb, Rotten Tomatoes, Metacritic

  1. На omdbapi.com/apikey.aspx выберите FREE и введите почту.
  2. Ключ придёт в письме. Обязательно нажмите в нём ссылку активации.
